# DataPlus

Repositório dedicado à curadoria, transformação e enriquecimento de bases de dados para análises estatísticas e projetos de ciência de dados.

## Sobre o projeto

O DataPlus reúne versões reformuladas de bases de dados existentes, desenvolvidas a partir de procedimentos de tratamento, transformação e engenharia de variáveis.

As modificações podem incluir a criação de índices, variáveis derivadas, classificações e outras características que ampliem as possibilidades de exploração e análise dos dados.

O objetivo é disponibilizar bases de dados documentadas e reutilizáveis, acompanhadas, sempre que possível, dos códigos utilizados em sua elaboração.

## Bases de dados

Cada base de dados possui um diretório próprio, com os arquivos disponíveis e a documentação referente às modificações realizadas.

| Base de dados | Descrição |
|---|---|
| Palmer Penguins | Base enriquecida com índices derivados e variáveis construídas a partir de medidas biométricas dos pinguins. |

Novas bases de dados serão adicionadas conforme o desenvolvimento de outros projetos e procedimentos de transformação.

## Organização

Os diretórios são organizados de acordo com cada base de dados e podem conter:

- **Dados:** arquivos originais e versões reformuladas.
- **Documentação:** descrição das variáveis, fórmulas, procedimentos e modificações realizadas.

A estrutura pode variar conforme as características e as necessidades de cada base.

## Fontes e licenças

As fontes dos dados originais e as respectivas condições de uso são informadas na documentação de cada base de dados. Antes de utilizar ou redistribuir os arquivos, consulte as condições aplicáveis.
